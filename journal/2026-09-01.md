# 1 September 2026 — the day the screen disagreed with the changelog

Written by hand rather than by the 05:45 job, because the auto entry reads
logs and git and today's most important findings came from the founder
looking at his own screen. Six of them would not appear in any log.

## The headline: four shipped features had never run

`renderGametime()` contained five initialisers written AFTER its `return`:

    return renderGametimeRest();
    try{ paintYou(); }catch(_){}
    try{ paintInvite(); }catch(_){}
    try{ tapeLoad(); }catch(_){}
    try{ handleRestore(); }catch(_){}
    try{ if(!SCHED) schedLoad(); }catch(_){}

`paintInvite`, `tapeLoad`, `handleRestore` and `schedLoad` had **no other
call site in the file** — every call site listed, not eyeballed. The invite
button, The Tape, the persistent @handle and the two-week schedule were all
built, all gated green, and none of them ever executed.

**117 suites passed over it.** Every one calls those functions directly.
Not one asserted that anything CALLS them. The founder's verdict on a
fortnight of work — "right now it looks the same" — was the literal truth.

They were also in the wrong function: `renderGametime()` paints the
Gametime tab; those cards live on the LANDING page. They now run from
`_statsReady()`.

Two more bugs were hiding behind the dead code and could only be found once
it ran:

- `tapeRender()` called `set(...)`, which is a LOCAL const in three other
  renderers and not a global. It threw ReferenceError into its own catch,
  so **The Tape had never rendered once since it shipped.**
- `tapeLoad()` gave up the first time `SB` was missing — which is every
  time, because readiness deliberately does not wait on the network.

## What the founder found by looking, that no test did

1. The rail read "Brewers at ..." on every tile — `.grWho` had
   `white-space:nowrap; text-overflow:ellipsis` **directly beneath a
   comment saying "NO nowrap"**. The home team, half of what the tile is
   for, hidden inside the one control that asks which game you are
   watching.
2. "GAME OF THE NIGHT" clipped to "GAME OF THE".
3. The landing had no wide layout: a 440px column inside 1850px. `go()`
   already did this for `predict` and `final`, and its own comment names
   the cost "on the machine the founder presents from". The landing — the
   screen every visitor meets first — was never included.
4. "final buzzer" printed over a BASEBALL card. Every sport already
   carries `L.end` ("final out", "final whistle", "final horn"); nothing
   reached for it.
5. The invite said "Free, no account needed" while linking to a LIVE room,
   which has always required one. False copy, already being shared.
6. No way out of practice. Both exits live on the landing's resume bar.
7. The Tape's answered state looked identical to a live selected option —
   a border tint, no glyph, and a 14px grey sentence as the entire reward.
   That is the payoff bug fixed in-game on 19 Aug, reintroduced.

## The schedule was never about ESPN

Founder: "why are you doing just ESPN games, we want national games."
ESPN is only the DATA SOURCE. Carriage is a separate list in
`host/leagues.js`, and it already contained Peacock, Paramount+, Netflix,
USA, TNT, TBS, the broadcast networks and Apple TV for the two leagues
Apple actually has.

The real bug: **nothing had ever been picking rooms.** The only cron
entries were two one-off scripts hard-dated to 28 and 31 August.
`host/pick-national.js` existed and had never been scheduled — so seven
scattered days had picks and the rest read "Not announced yet". Friday was
never empty; it had Liverpool at Ipswich on USA Network and two Apple TV
baseball games.

Fixed: picks generated for all 14 days, manifests built for the ones that
had none, and `host/fill-horizon.sh` cron'd at 03:40 so it cannot rot
again. All 14 days now list rooms; zero unlistable.

## The tip-off email stopped being a clock

23 of the 26 Premier League rooms this product has ever hosted kicked off
BEFORE the old 10:45 send; 21 before the 09:13 draft. The send now targets
90 minutes before the day's first kickoff, never later than 10:45, owned by
`host/tipoff-when.js` and shared by all four jobs. Moving only the send
would have been worse than useless — it would come due at 05:30 and find no
draft. First real early day is Saturday 5 Sept: 04:30 kickoff, 03:52 send.

## CFB, two days before a CFB go-live

`nflTwoMinuteScore` was silent in 8 of 8 college games and 0 of 30 NFL
ones. The two-minute warning is an NFL rule; college football has none, so
the resolver returned null every time. Thursday's slate is 11 college
games, each of which would have carried a guaranteed dead question. Fixed
with a clock fallback keyed off THE GAME, not the quarter — the first cut
keyed off the quarter and made NFL Q1/Q3 start answering, turning two
honest voids into "Nobody scored".

## What I broke, and what it cost

- **Firebase auth/too-many-requests.** Eight gate runs, ~126 suites each,
  and this app mints an anonymous account on PAGE LOAD. Tripped the limit
  on this IP for 4+ hours. Proven per-IP by the founder loading the site on
  cellular and signing in fine — production was never affected. Testing the
  app degraded the app.
- Killed my own shell four times with `pgrep -f` / `pkill -f` matching
  their own command lines. Twice that killed a 30-minute gate.
- Deduped a manifest on the wrong column and deleted the backup in the same
  command, dropping 26 rows to 4. Rebuilt it.
- Wrote a QA check whose regex backtracked for two minutes on a 1.8MB file.
- Wrote `qa/landing-wired.js` to read only `--file`, so inside the gate it
  fell back to `index.html` and graded the LIVE build while reporting with
  confidence. A suite that grades the wrong file is worse than one that
  does not run.
- Put the practice-exit toggle after `return renderGametimeRest()` — the
  same dead-code bug I had fixed that morning, in the same function, which
  has three of those returns.

## Open, and deliberately not done today

- **Practice is nine innings.** Right for a hosted night, wrong for a demo.
  `liveRounds()` has 8 call sites and five suites assert on round counts;
  it gets its own change and its own gate.
- **Doubleheader nightId collision.** Friday has Tigers at Guardians twice;
  both collapse to `slate-2026-09-04-det-cle`. The picker chose the 4:10 PM
  Apple TV game, the schedule shows the 11:10 AM one. The fix changes room
  identity — not two days before go-live.
- **Account on page load → account on first play.** The root cause of the
  auth limit, and the only way any funnel number becomes meaningful.
  Founder-awake change.
- **QA suites consume production auth.** `qa/fakebase.js` exists; the
  browser suites should stub rather than mint real sign-ins.
- `references/multisport/question-banks.js` still says MLB gets three
  rounds — "Not nine" — contradicting the every-inning rule. Only one gate
  suite reads it, so it cannot change live grading, but it is very likely
  why the rule kept reverting.

## The lesson worth keeping

Every failure today was the same shape: **something existed and nothing ran
it, and the tests confirmed it existed.** A function that works is not a
feature that runs. Two screenshots found more in thirty seconds than three
green gate runs did.
